# Проверка перед сдачей

Проверки ниже требуют Unity и наушников. Поставьте отметки только после фактического выполнения. Наличие кода не заменяет демонстрацию запуска.

1. Открыть проект Unity 6000.6.0f1, дождаться импорта; выполнить Build workshop scenes и Validate scenes; убедиться, что Console не содержит ошибок/предупреждений. Запустить все EditMode-тесты через Test Runner, сохранить результат.
2. В Variant_Андижан проверить стол FBX, кресло OBJ, лампу GLB: URP-материалы, настройки импорта, размеры по Bounds, Scale Factor 1, Bake Axis Conversion. Рядом куб 1 м. Измерения из исходных файлов есть в model_inventory.json; подтвердить их в Unity.
3. Взять кресло, лампу, радио и ключи через XR Simulator; отпустить/бросить на пол и стол. Проверить Rigidbody, BoxCollider / Convex MeshCollider и отсутствие проваливания. Повторить E/Q в резервном режиме ПК.
4. Выделить Fan FBX: Generic, FanLoop, Loop Time. Показать Animator Controller и минимум два полных оборота без стыка.
5. У кресла проверить LOD0/LOD1/LOD2/Culled при удалении. Дистанция около 30 м — ориентир, порог экранного размера зависит от FOV. Для таблицы Stats зафиксировать одинаковые положение камеры и качество: сначала ForceLOD(0), затем ForceLOD(-1), при удалении 10–15 м. Снять Tris, Batches, FPS отдельно. ForceLOD(-1) вернуть после измерений.
6. Esc / primary button: показать Music/SFX/Ambient, ползунки, 0 → -80 dB, 1 → 0 dB. Закрыть и вновь запустить Play: значения сохранились. При паузе показать Paused с переходом 0.5 с, при закрытии Normal. Приглушение родительских шин не заменяет настройки пользовательских громкостей.
7. В наушниках слушать радио при повороте на 90°/180°, удалении до 15 м и переносе в руке. Радио Logarithmic 1/10 м: maxDistance не является жёстким отключением; с 15 м оно может быть слышно. Без HRTF различимость переда/зада ограничена.
8. Вентилятор: Custom Rolloff, Spread 90°, нулевой сигнал вне 4 м. Для изоляции на время проверки отключить остальные Ambient-источники, затем восстановить их. Слушать дрон при пролёте: радиус 5 м, скорость 9 м/с, Doppler 1.
9. С радио пройти через дверь наружу и обратно: показать Room Reverb Zone и услышать разницу. Зона сферическая и аппроксимирует комнату; её границы видны в Scene View.
10. Вариант 4: grip/select + trigger активируют двигатель автомобиля; аналогично компрессор. Уронить ключ с небольшой высоты и бросить сильнее: громкость удара возрастает, pitch меняется, доступны три клипа.
11. Скрыть куб F1; записать 1–2 минуты Game View со звуком приложения. Скриншоты и видео брать из Unity, не выдавать исходный рендер Blender за запись работы сцены.
12. Заполнить группу, Stats, слуховые наблюдения, добавить скриншоты Model/Rig/Materials, AudioClip, AudioSource, Mixer и ссылку на видео в отчёт. Убедиться, что разрешение автора на помощь/лицензии соответствует правилам преподавателя. Изучить скрипты и уметь объяснить каждую строку.

## Сценарий видео (90 секунд)

| Время | Показать |
|---|---|
| 0–15 с | Общий вид мастерской, реальные размеры, модели трёх форматов |
| 15–30 с | Радио: поворот головы, захват, перенос, trigger on/off |
| 30–45 с | Ключ: мягкое падение и сильный удар; двигатель по активации |
| 45–60 с | Вентилятор: анимация и резкий cutoff; пролёт дрона с Доплером |
| 60–75 с | Радио внутри/снаружи комнаты; переключение LOD |
| 75–90 с | Меню, ползунки, снимки Paused/Normal; Console и Mixer |

## Остаток требований документа

Не предоставлены проекты работ № 4–5, поэтому XR-сцена, захват и меню реализованы с нуля. Большинство ресурсов оригинальные, а не самостоятельно найденные внешние модели/записи. Группа неизвестна. Runtime-проверки, реальные измерения Stats, видео и скриншоты требуют локального Unity. Эти пункты остаются открытыми; баллы и успешная защита не заявляются.
