# Разбор реализации для защиты

## ImpactSound.cs

RequireComponent гарантирует Rigidbody и AudioSource. Awake получает источник и устанавливает 3D-режим. OnCollisionEnter читает relativeVelocity: скорость сближения тел, а не только скорость ключа. Слишком слабый удар, пустой набор клипов и повтор в пределах cooldown отбрасываются. Начальное время равно отрицательной бесконечности, поэтому первый удар не подавляется. InverseLerp переводит диапазон 0.3–5 м/с в 0–1 и ограничивает результат. PlayOneShot проигрывает выбранный вариант без остановки уже звучащего эффекта. pitch 0.9–1.1 даёт небольшое разнообразие. Пустые ссылки защищены проверками.

## InteractableAudio.cs / AudioSwitch.cs

OnEnable подписывает методы на selectEntered/selectExited/activated, OnDisable снимает ровно те же подписки. Параметры событий соответствуют XR Toolkit 2.5.4. Feedback и loop — разные AudioSource, поэтому сигнал захвата/включения не прерывает музыку. Радио включается/выключается по trigger, если оно выбрано; источник остаётся дочерним самому переносимому объекту. Для неподвижного двигателя используется XRSimpleInteractable, для предметов — XRGrabInteractable. Методы public также вызываются резервным управлением ПК.

## OrbitingSource.cs

Положение вычисляется через cos/sin на окружности. Угловая скорость = линейная скорость / радиус, то есть 9/5 радиан в секунду. FixedUpdate и MovePosition обновляют кинематическое физическое тело, чтобы движок мог вычислять скорость источника для Доплера. Дрон не имеет коллайдера и служит демонстрацией звука, не симуляцией полёта. Направление касательной используется для поворота модели.

## WorkshopMenu.cs

Ползунки инициализируются в Start, а не Awake: это корректный момент для AudioMixer.SetFloat. PlayerPrefs хранит пользовательские значения линейной громкости. В децибелы они переводятся через 20·log10(max(v,0.0001)); порог защищает от log10(0), минимум −80 dB. Открытое меню останавливает Time.timeScale, но не аудиопроцесс. Снимки меняют дополнительные родительские ducking-шины, поскольку exposed-параметры пользовательских групп имеют приоритет над значениями snapshots. Canvas размещается перед камерой и доступен VR-лучу. Escape и A/X контроллера вызывают тот же Toggle.

## DesktopWorkshopController.cs

Этот компонент — удобное резервное управление без шлема. CharacterController обеспечивает столкновение пользователя со стенами, deltaTime делает скорость независимой от FPS. Поворот камеры по двум осям ограничен по вертикали. Raycast проверяет объект до 3 м; выбранные XR-предметы другим способом не перехватываются. При захвате сохраняются исходные свойства Rigidbody, кinematic удержание использует ContinuousSpeculative, при отпускании настройки восстанавливаются. Q задаёт скорость броска. F2 включает оригинальный XR Device Simulator, контроллеры и TrackedPoseDriver; резервный ввод перестаёт двигать камеру. Если обнаружен работающий реальный XRDisplaySubsystem, этот резервный режим отключается.

## WorkshopImportSettings.cs

AssetPostprocessor работает до импорта и только для папок проекта. Масштаб и оси исправляются в импортёре; геометрия не масштабируется в сцене. У Fan есть Generic-анимация, остальные FBX статические. 3D-клипы становятся mono; фон — Streaming. Нормальные карты получают Texture Type Normal Map, текстуры ограничены 1024 px с ASTC для Android. Эти настройки сами по себе не подтверждают работоспособность сборки Android.

## WorkshopBuilder.cs

Меню редактора строит сцены из настоящих FBX/OBJ/GLB. AssetDatabase загружает ресурсы и сохраняет вспомогательные URP-материалы, Animator Controller, collision hull и input-action references. PackageInfo находит установленный XR Toolkit; копируются его официальные samples, включая metadata с GUID для ссылок prefabs. Новые модели находятся в родительских объектах с единичным масштабом. Дорогой кресельный render mesh не используется для ConvexCollider: отдельный простой hull дешевле и не превышает лимит выпуклых граней. LOD1 содержит половину треугольников, LOD2 — proxy. UI кнопка сохраняется как persistent UnityEvent, а не потерянная после сохранения runtime-подписка.

ValidateScenes ловит структурные ошибки сцены: лишний Listener, неверную маршрутизацию, stereo-импорт 3D-клипов, отсутствующую физику захвата, неверный LOD и корректирующие scale/rotation. Это ещё не тест слухового восприятия или физики в Play Mode. WorkshopTests добавляет проверки поведения функций громкости и настроек варианта. Реальный запуск обязателен.
